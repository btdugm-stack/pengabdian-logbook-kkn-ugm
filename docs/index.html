PoC Pengabdian: Logbook KKN

Aplikasi berbasis PHP Native + MySQL untuk manajemen logbook KKN (Kuliah Kerja Nyata) mahasiswa UGM dengan fitur dual-role: mahasiswa untuk input logbook, dan role umum untuk search dan pemetaan lokasi.

✨ Fitur Aplikasi

🔐 Autentikasi Mahasiswa

  • Simulasi Google SSO - Login menggunakan email yang sudah terdaftar
  • Session Management - Manajemen sesi dengan PHP native
  • Role-based Access - Dashboard terpisah untuk mahasiswa dan public
  • Biodata Form - Edit profil lengkap (nama, TTL, fakultas, kontak)

📝 Input Logbook

  • Datetime Logging - Catat tanggal & waktu kegiatan
  • Master Data Dynamic - Auto-create dropdown data (tema, program, lokasi)
  • Health Status Tracking - Monitor kesehatan (Normal/Sakit/Izin/Kendala)
  • Geolocation Input - Koordinat latitude/longitude manual atau dari maps
  • Community Impact - Jumlah masyarakat yang terlibat
  • Draft & Submit - Simpan sebagai draft atau submit langsung

🔎 Public Search

  • Search Mahasiswa - Cari data student dengan filter fakultas
  • Search Logbook - Cari logbook keseluruhan dengan berbagai filter
  • View-Only Access - Public users tidak perlu login
  • Advanced Filtering - By health status, student, tema, program, lokasi

🗺️ Pemetaan Lokasi

  • Leaflet.js Integration - Peta interaktif dengan OpenStreetMap
  • Color-coded Markers - Merah (Sakit), Orange (Kendala/Izin), Biru (Normal)
  • Popup Info - Detail lokasi, mahasiswa, dan status pada marker
  • Automatic Bounds - Auto-zoom ke area dengan data

📊 Dashboard & Analytics

  • KPI Cards - Total logbook, masyarakat, status kesehatan, lokasi
  • Personal Dashboard - Ringkasan data per mahasiswa
  • System-wide Stats - Statistik keseluruhan aplikasi
  • Data Visualization - Pills dan cards untuk quick insights

📥 Export Data

  • CSV Export - Download logbook pribadi dalam format CSV
  • Full Metadata - Semua field logbook + join data
  • Authenticated Only - Hanya mahasiswa yang login bisa export
  • Direct Download - Instant file generation

⚙️ Instalasi & Setup

1. Prerequisites

  • Laragon (Windows) atau XAMPP (Mac/Linux)
  • PHP 7.4+ dengan PDO MySQL extension
  • MySQL 5.7+
  • Git (untuk clone repository)

2. Clone Repository

git clone https://github.com/btdugm-stack/pengabdian-logbook-kkn-ugm.git
cd pengabdian-logbook-kkn-ugm

3. Setup Database

  1. Buka phpMyAdmin (http://localhost/phpmyadmin)
  2. Buat database baru: logbook_kkn
  3. Import file database.sql ke database tersebut

4. Konfigurasi Aplikasi

Edit file config.php:

<?php
define('APP_NAME', 'Pengabdian: Logbook KKN');
define('APP_BASE_URL', 'http://localhost/pengabdian-logbook-kkn-ugm');

define('DB_HOST', '127.0.0.1');
define('DB_NAME', 'logbook_kkn');
define('DB_USER', 'root');
define('DB_PASS', ''); // Laragon kosong
?>

5. Akses Aplikasi

Buka browser ke:

http://localhost/pengabdian-logbook-kkn-ugm

🏗️ Arsitektur Sistem

Single-File MVC Architecture

Project menggunakan pola monolithic single-file untuk PoC yang sederhana:

  • index.php (796 lines) - Semua routing, business logic, dan views terpusat
  • db.php (89 lines) - Database connection, helper functions
  • config.php - Constants dan credentials
  • assets/style.css - Styling responsive custom

Database Model

6 Tables dengan Foreign Keys:

  • students - User account & biodata
  • logbooks - Core records
  • themes - Master data tema
  • programs - Master data program kerja
  • activity_types - Master data jenis kegiatan
  • locations - Master data lokasi + geolocation

Request Flow

  1. GET $_GET['page'] - Route ke halaman
  2. POST $_POST['action'] - Dispatch ke handler
  3. Business Logic - Validasi & database ops
  4. View Rendering - layout_start/end()
  5. Response - HTML + Flash messages

Pages Available

  • home - Landing page
  • login - Google SSO simulasi
  • dashboard - Mahasiswa dashboard
  • data_kkn - Biodata form
  • logbook_form - Input logbook
  • my_logbooks, map, export - Data views
  • public_students, public_logbooks, public_map - Public views

Master Data Pattern

  • get_or_create_master() - Auto-insert jika data baru
  • master_options() - Fetch dropdown data
  • Dual input fields - Select existing atau input baru
  • Immediate availability - Data langsung jadi dropdown
